# Clade Studio 0.1.1

A maintenance prerelease for geometry checking, bounded routing and artistic editing. This release includes the fixes reviewed in PR #1.

## Fixed and improved

- Large forks count candidate enumeration against the routing work budget, avoiding unbounded pair construction. Interrupted trials restore their exact geometry, and exact work/evaluation exhaustion is disclosed.
- Shared-junction incidence checks report **Incomplete** when their budget expires; unchecked attachments cannot receive a Pass.
- Historical artistic copies defer QA during junction, label and waypoint dragging. Release validates the final edit; cancellation and one-step undo are retained.
- Geometry checks detect extended incident overlap and self-crossing stems, count findings beyond the bounded issue examples, and use indexed geometry for larger drawings.
- Topology inspection uses aligned, spacing-aware geometry. Readability proposals account for incomplete checks, and fitting controls use clearer names.

## Project compatibility

Project format remains V4. Supported older projects preserve their stored artwork and historical QA through the original validation profiles. Current checks and exported QA use **compound-v3**. Older application builds may reject newly saved current-profile views; use 0.1.1 to continue editing those projects.

## Downloads and quick start

**Browser ZIP — `clade-studio-0.1.1-browser.zip`:** extract and serve the folder over local HTTP. With Python 3 installed, run inside the extracted folder:

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

**Source ZIP — `clade-studio-0.1.1-source.zip`:** requires Node.js 22.18 or later and npm. Extract, then run:

```sh
npm ci
npm run dev
```

Open **http://127.0.0.1:4173**. Stop either server with **Ctrl+C**. Opening HTML directly from disk is unsupported.

Each ZIP has a companion `.sha256` file and an internal `release-manifest.json` with file hashes and component licenses. Verify a download from its folder with:

```sh
sha256sum -c clade-studio-0.1.1-browser.zip.sha256
sha256sum -c clade-studio-0.1.1-source.zip.sha256
```

## Verification and limitations

All 239 automated tests, strict TypeScript checking, build identity, source checksums and release-package inventories pass. Automated controller tests cover historical 600-tip drags; live browser and device-font verification were not performed for this release.

Layouts can still have contacts, clearance problems, unavailable font measurements or incomplete checks. Those findings remain Draft. Routing is a bounded heuristic, not a guarantee of an overlap-free drawing. There is no persistent autosave: save a project before closing the tab.

The project is **not actively maintained**. Owner development may be sporadic or absent; maintain an independent fork if you need ongoing improvements or support.

Original software is **0BSD**. Bundled data retain their **CC BY 4.0** or **CC0** terms; see `REDISTRIBUTION.md`, the included notices and each archive's manifest.
