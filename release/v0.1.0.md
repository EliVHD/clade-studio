# Clade Studio 0.1.0

The first release of Clade Studio: a local browser app for turning supplied trees into editable figures with sources and methods attached.

## Included

- Newick import, complete-source search and a zoomable read-only Explore viewer.
- Rectangular, circular and fan cladograms; source-distance phylograms; supplied-rank classifications; and unrooted equal-angle/daylight layouts.
- Junction and label adjustments, pins, readability previews, artistic copies and Organic silhouette fitting.
- Editable V4 project saves with V1–V3 migration.
- Labeled/unlabeled SVG export packages with source mappings, QA, references and Sources & Methods.
- Offline datasets from Hug et al. (2016), Upham et al. (2019), dos Reis et al. (2018) and Kew release 4.0, plus a bundled guide.

## Downloads and quick start

**Browser ZIP — `clade-studio-0.1.0-browser.zip`:** extract and serve the extracted folder over local HTTP. For example, with Python 3 installed, run this inside that folder:

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

**Source ZIP — `clade-studio-0.1.0-source.zip`:** requires Node.js 22.18 or later and npm. Extract, then run:

```sh
npm ci
npm run dev
```

Open **http://127.0.0.1:4173**. Stop either server with **Ctrl+C**. Use **Guide** in the app for the walkthrough. Opening the HTML directly from disk is unsupported.

Each ZIP has a companion `.sha256` file and an internal `release-manifest.json` with file hashes and component licenses. On systems with `sha256sum`, verify a download from its folder with:

```sh
sha256sum -c clade-studio-0.1.0-browser.zip.sha256
```

## Known limitations

- Layout and fitting can leave overlaps or spacing issues. Draft exports disclose unresolved geometry, font measurements and work limits; review the drawing before using it.
- There is no persistent autosave. Download a project before closing; editing images remain embedded in project files, including those inside export packages.
- One source per project. No online organism lookup, relationship inference, dated/fossil layouts, trait analysis or cross-source comparison.
- Explore is nonmetric and read-only. Its temporary viewing summaries do not change the exported drawing. Adaptive unrooted Explore is not included.
- Newick inputs are limited to 20 MB, 100,000 nodes and depth 800; project imports to 50 MB. Large inputs should be explored in full and drawn as selected subsets.
- Text depends on available browser fonts. Changed font measurements can require regeneration before export.
