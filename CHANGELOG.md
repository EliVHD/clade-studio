# Changelog

## 0.1.0 — first release

Initial local authoring release of Clade Studio.

- Import Newick trees and save editable V4 projects, with migration from V1–V3.
- Search the full source and explore large trees in a separate read-only rectangular, circular or fan viewer.
- Create rectangular, circular and fan cladograms, documented source-distance phylograms, supplied-rank classifications and unrooted equal-angle/daylight layouts.
- Refine shared junctions and labels, pin positions, preview readability changes and create independent artistic copies.
- Shape Organic artwork with editable curves, endpoint borders, image overlays and constrained fitting previews.
- Export paired labeled/unlabeled SVGs with exact source mappings, membership records, QA, references and Sources & Methods.
- Work offline with the bundled Hug, Upham, dos Reis and Kew trees and an in-app authoring guide.
- Build verified browser/source release archives with component licenses and SHA256 inventories.

See [release notes](release/v0.1.0.md) for setup, release assets and known limitations. This entry describes the prepared version; GitHub publication has not yet taken place.
